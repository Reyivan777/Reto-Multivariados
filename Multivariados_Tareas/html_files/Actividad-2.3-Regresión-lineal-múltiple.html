2. Método de mínimos cuadrados

El modelo de regresión lineal múltiple puede expresarse como:

\[Y = X\beta + \varepsilon\]

El estimador de mínimos cuadrados de los coeficientes es:

\[\hat{\beta} = (X^TX)^{-1}X^TY\]

Se utiliza esta expresión para calcular los coeficientes del modelo manualmente mediante operaciones matriciales.

# Vector de la variable dependiente
Y <- as.matrix(datos$Resistencia)

# Matriz de diseño
X <- cbind(
  1,
  datos$Longitud,
  datos$AlturaMatriz,
  datos$AlturaPoste,
  datos$AlturaAmarre
)

colnames(X) <- c(
  "Intercepto",
  "Longitud",
  "AlturaMatriz",
  "AlturaPoste",
  "AlturaAmarre"
)

# Coeficientes por mínimos cuadrados
beta_hat <- solve(t(X) %*% X) %*%
            t(X) %*%
            Y

beta_hat
##                     [,1]
## Intercepto   1.068134045
## Longitud     2.484232443
## AlturaMatriz 0.008553692
## AlturaPoste  0.622369141
## AlturaAmarre 2.293923555

Los coeficientes obtenidos son aproximadamente:

\[\hat{\beta}_0 = 1.0681\]

\[\hat{\beta}_1 = 2.4842\]

\[\hat{\beta}_2 = 0.00855\]

\[\hat{\beta}_3 = 0.6224\]

\[\hat{\beta}_4 = 2.2939\]

Por lo tanto, el modelo completo estimado es:

\[\hat{Y} = 1.0681 + 2.4842X_1 + 0.00855X_2 + 0.6224X_3 + 2.2939X_4\]

Valores estimados y residuos

Los valores predichos se calculan mediante:

\[\hat{Y}=X\hat{\beta}\]

y los residuos mediante:

\[e=Y-\hat{Y}\]

# Valores estimados
Y_hat <- X %*% beta_hat

# Residuos
residuos_mc <- Y - Y_hat

# Suma de cuadrados del error
SSE <- sum(residuos_mc^2)

SSE
## [1] 61.597

El método de mínimos cuadrados encuentra los coeficientes que hacen que la suma de los residuos al cuadrado sea lo más pequeña posible.

4.5 Colinealidad

Se calcula manualmente el factor de inflación de la varianza:

\[VIF_j = \frac{1}{1-R_j^2}\]

predictores <-
  names(coef(modelo_mejor))[-1]

VIF <- numeric(
  length(predictores)
)

names(VIF) <- predictores

for(i in seq_along(predictores)){
  
  y_aux <- predictores[i]
  
  x_aux <- predictores[-i]
  
  formula_aux <- as.formula(
    paste(
      y_aux,
      "~",
      paste(
        x_aux,
        collapse = " + "
      )
    )
  )
  
  modelo_aux <- lm(
    formula_aux,
    data = datos
  )
  
  R2_aux <-
    summary(modelo_aux)$r.squared
  
  VIF[i] <-
    1 / (1 - R2_aux)
}
