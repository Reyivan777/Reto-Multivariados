2. Tendencia y estacionalidad

Serie de tiempo

plot(ventas_ts,
     type = "o",
     xlab = "Año",
     ylab = "Ventas (miles)",
     main = "Ventas trimestrales de televisores")

La serie no es estacionaria, ya que presenta una tendencia general creciente y un patrón estacional trimestral repetitivo. En particular, el segundo trimestre suele presentar las ventas más bajas y el cuarto las más altas.

Autocorrelación (ACF)

acf(as.numeric(ventas_ts),
    lag.max = 12,
    xlab = "Rezago (trimestres)",
    main = "Autocorrelación de las ventas")

La ACF muestra un valor importante en el rezago 4, consistente con una estacionalidad trimestral: observaciones del mismo trimestre en años consecutivos tienden a comportarse de manera semejante.

Modelos aditivo y multiplicativo

Se prueban las dos formas de descomposición para comparar cuál representa mejor la serie.

descomp_add <- decompose(ventas_ts, type = "additive")
descomp_mult <- decompose(ventas_ts, type = "multiplicative")

plot(descomp_add)

plot(descomp_mult)

Ambas descomposiciones representan el patrón estacional. La elección final entre una estructura aditiva o multiplicativa se realiza comparando los errores de pronóstico de los modelos ajustados.

\[\hat{y}=4.7903+0.2533t-0.00623t^2\]

Tanto el término lineal (\(p=3.56\times10^{-5}\)) como el término cuadrático (\(p=0.0204\)) son significativos. El modelo es globalmente significativo y alcanza un \(R^2=0.9484\). El coeficiente negativo de \(t^2\) indica que las ventas siguen aumentando, pero el ritmo de crecimiento se va reduciendo con el tiempo.

6. MSE y MAPE

Se comparan tres modelos: aditivo lineal, multiplicativo lineal y multiplicativo cuadrático.

pred_add_lin <- fitted(modelo_lineal_add) + estacional_add
pred_mult_lin <- fitted(modelo_lineal_mult) * estacional_mult
pred_mult_cuad <- fitted(modelo_cuad_mult) * estacional_mult

metricas <- function(real, pred) {
  c(
    MSE = mean((real - pred)^2, na.rm = TRUE),
    MAPE = mean(abs((real - pred) / real), na.rm = TRUE) * 100
  )
}

comparacion <- rbind(
  "Aditivo lineal" = metricas(ventas, pred_add_lin),
  "Multiplicativo lineal" = metricas(ventas, pred_mult_lin),
  "Multiplicativo cuadrático" = metricas(ventas, pred_mult_cuad)
)

round(comparacion, 4)
##                              MSE   MAPE
## Aditivo lineal            0.0329 2.4921
## Multiplicativo lineal     0.0330 2.4395
## Multiplicativo cuadrático 0.0219 1.9493

El modelo multiplicativo cuadrático presenta los menores errores, con un Mean Squared Error (MSE) de 0.0219 y un Mean Absolute Percentage Error (MAPE) de 1.9493%. Por lo tanto, es el mejor de los tres modelos evaluados. Los dos modelos lineales presentan resultados muy similares entre sí, pero ambos tienen errores mayores.

mejor_MSE <- rownames(comparacion)[which.min(comparacion[, "MSE"])]
mejor_MAPE <- rownames(comparacion)[which.min(comparacion[, "MAPE"])]

7. Pronóstico del siguiente año

Se calculan los pronósticos de los cuatro trimestres del año 5 para los tres modelos analizados.

futuro <- data.frame(
  tiempo = 17:20,
  tiempo2 = (17:20)^2
)

est_add_fut <- as.numeric(indice_add[1:4])
est_mult_fut <- as.numeric(indice_mult[1:4])

pron_add_lin <- predict(modelo_lineal_add, newdata = futuro) + est_add_fut
pron_mult_lin <- predict(modelo_lineal_mult, newdata = futuro) * est_mult_fut
pron_mult_cuad <- predict(modelo_cuad_mult, newdata = futuro) * est_mult_fut

pronosticos <- data.frame(
  Año = rep(5, 4),

Conclusión

La serie de ventas no es estacionaria porque presenta una tendencia creciente y estacionalidad trimestral. Después de obtener las series desestacionalizadas se ajustaron tres modelos. El modelo multiplicativo cuadrático fue el mejor, con MSE = 0.0219 y MAPE = 1.9493%, y sus términos resultaron estadísticamente significativos. Por ello se utiliza para pronosticar el año 5, manteniendo el patrón estacional de menores ventas en el trimestre 2 y mayores ventas en el trimestre 4.
