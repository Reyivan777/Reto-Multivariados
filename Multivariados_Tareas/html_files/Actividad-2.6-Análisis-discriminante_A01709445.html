1. Preparación de los datos

El objetivo del análisis es clasificar las viviendas de acuerdo con su nivel de calidad de construcción mediante un análisis discriminante lineal (LDA).

La variable grade representa la calidad de construcción de la vivienda. Para utilizarla como variable categórica dependiente se agrupa en tres niveles:

  • Baja: grade <= 6
  • Media: grade entre 7 y 8
  • Alta: grade >= 9

Esta agrupación permite trabajar con categorías suficientemente representadas y facilita la interpretación del modelo.

2. Definición de la variable dependiente

Se crea la variable categórica grade_cat a partir de grade.

datos$grade_cat <- cut(
  datos$grade,
  breaks = c(-Inf, 6, 8, Inf),
  labels = c("Baja", "Media", "Alta")

datos$grade_cat <- factor(

5. Segmentación original de los datos

Antes de construir el modelo se busca identificar qué variables presentan mayores diferencias entre los tres grupos.

Para ello se calcula el estadístico F de un ANOVA para cada predictor. Un valor F más grande indica una mayor diferencia entre las medias de los grupos.

f_valores <- sapply(
  predictores,
  function(variable) {

    modelo_anova <- aov(
      muestra[[variable]] ~ muestra$grade_cat
    )

    summary(modelo_anova)[[1]][["F value"]][1]
  }
)

ranking_discriminacion <- data.frame(
  Variable = names(f_valores),
  F = as.numeric(f_valores)
)

ranking_discriminacion <- ranking_discriminacion[
  order(ranking_discriminacion$F, decreasing = TRUE),
]

rownames(ranking_discriminacion) <- NULL

6.2 Probabilidades a priori

Las probabilidades a priori representan la probabilidad inicial de pertenecer a cada grupo antes de considerar los predictores.

Se calculan mediante:

\[ P(G_k)=\frac{n_k}{n} \]

donde \(n_k\) es el número de observaciones del grupo y \(n\) es el tamaño total de la muestra.

7. Construcción del modelo LDA

El análisis discriminante lineal busca construir combinaciones lineales de los predictores que permitan separar lo mejor posible los grupos.

La forma general de una función discriminante es:

\[ LD_k = a_1X_1+a_2X_2+\cdots+a_pX_p \]

donde los coeficientes \(a_i\) son determinados por el modelo.

# Construir fórmula
formula_lda <- as.formula(
  paste(
    "grade_cat ~",
    paste(
      predictores,
      collapse = " + "
    )
  )
)

formula_lda

##     floors + sqft_basement + yr_built + lat + long + sqft_living15 + 
##     sqft_lot15
# Ajustar modelo
modelo_lda <- MASS::lda(
  formula_lda,
  data = muestra

8. Funciones lineales discriminantes

El número máximo de funciones discriminantes es:

\[ \min(p,g-1) \]

donde \(p\) es el número de predictores y \(g\) es el número de grupos.

En este caso:

\[ g-1=3-1=2 \]

por lo que se obtienen dos funciones: LD1 y LD2.

12. Evaluación de la precisión del modelo

Para evaluar el poder predictivo se utiliza validación cruzada Leave-One-Out (LOOCV).

En cada iteración se deja fuera una observación, el modelo se construye con las 299 restantes y después intenta clasificar la observación excluida. El proceso se repite para las 300 viviendas.

Este procedimiento ofrece una evaluación más realista que medir el desempeño con las mismas observaciones utilizadas para ajustar el modelo.

modelo_cv <- MASS::lda(
  formula_lda,
  data = muestra,
  CV = TRUE
)

clase_real <- muestra$grade_cat

clase_predicha <- modelo_cv$class

12.2 Precisión global

La precisión se calcula como:

\[ Precisión = \frac{\text{Predicciones correctas}} {\text{Total de predicciones}} \times 100 \]

precision <- mean(
  clase_real == clase_predicha
)

12.3 Porcentaje de error

\[ Error = 100 - Precisión \]

13. Validación de supuestos

El análisis discriminante lineal supone principalmente:

  1. Normalidad multivariada dentro de cada grupo.
  2. Igualdad de las matrices de varianzas y covarianzas entre grupos.

13.1 Normalidad multivariada

Se utiliza la prueba de Mardia.

Las hipótesis son:

\[ H_0: \text{Los datos siguen una distribución normal multivariada} \]

\[ H_1: \text{Los datos no siguen una distribución normal multivariada} \]

Se utiliza un nivel de significancia de:

\[ \alpha = 0.05 \]

Si \(p < 0.05\), se rechaza la hipótesis nula.

resultados_normalidad <- list()

for (grupo in levels(muestra$grade_cat)) {

  datos_grupo <- muestra[
    muestra$grade_cat == grupo,
    predictores
  ]

  )

  cat(

    data = datos_grupo,

}

14. Homogeneidad de matrices de covarianzas

Para comprobar si los grupos presentan matrices de covarianzas semejantes se utiliza la prueba M de Box.

Las hipótesis son:

\[ H_0: \Sigma_{Baja} = \Sigma_{Media} = \Sigma_{Alta} \]

\[ H_1: \text{Al menos una matriz de covarianzas es diferente} \]

Si \(p < 0.05\), se rechaza la igualdad de matrices de covarianzas.

15. Conclusiones

El análisis muestra que las características que más ayudan a distinguir la calidad de las viviendas son principalmente la superficie habitable (sqft_living), el número de baños y la superficie habitable de viviendas cercanas (sqft_living15).

El modelo LDA alcanza una precisión de 78.67%, con un error de 21.33%. Su mejor desempeño ocurre en viviendas de calidad media, mientras que presenta más dificultades para identificar las categorías baja y alta.

Además, las pruebas de Mardia y M de Box muestran que no se cumplen los supuestos de normalidad multivariada ni de igualdad de matrices de covarianzas. Por esta razón, aunque el modelo logra una clasificación razonable, sus resultados deben interpretarse con precaución.
